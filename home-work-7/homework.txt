2. Работа с блочными и инлайновыми элементами:
Создайте простую HTML-страницу с использованием основных тегов <div> и <span>.

Div (или тег <div>) – это блоковый элемент, который используется для создания структуры веб-страниц. Мы используем его для группирования различных элементов и создания "контейнеров" на веб-странице. Тег div чрезвычайно гибок, позволяя нам применять CSS стили для форматирования разделов страницы, таких как заголовки, навигационные панели, основной контент и футеры.
Span – это инлайновый (встроенный или строковый) элемент, представленный тегом <span>. Мы используем span для стилизации или отличия частей текста в пределах других элементов, не создавая при этом новых блоков. Например, мы можем использовать span для изменения цвета, шрифта или других стилистических характеристик отдельных слов или фраз в абзаце, не нарушая при этом общего потока документа.

4. Изучение CSS свойств :
Используйте разные значения для свойства display (например, block, inline, flex) к элементам на странице и наблюдайте за изменениями.

Свойство display
Свойствоdisplay CSS - это механизм, используемый для контроля над способом отображения элементов на веб-странице. Это свойство определяет, как элемент должен быть показан в документе, и позволяет нам изменять поведение элементов, превращая их из блочных в инлайновые, или наоборот, а также скрывать или изменять на другие типы отображения.

Мы используем displayдля достижения различных целей в веб-дизайне:

Изменение типа элемента: Например, преобразование инлайнового элемента ( display: inline;) в блочный ( display: block;) или наоборот.
Создание гибких макетов: С помощью display: flex;или display: grid;мы можем создавать сложные адаптивные макеты, которые реагируют на изменения размера экрана.
Скрытие элементов: элемент display: none;исчезает с веб-страницы и не занимает пространства, в отличие от visibility: hidden;, где элемент остается видимым, но становится прозрачным.
Создание инлайновых блоков: display: inline-block; позволяет элементам выравниваться как инлайновые, но обладать свойствами блоковых элементов.
Понимание и умение применять свойство displayважно для эффективной верстки и дизайна веб-страниц, поскольку это дает нам больший контроль над тем, как элементы размещаются и взаимодействуют между собой.

Используйте box-sizing для изменения способа вычисления размеров блоков.

box-sizing
Box-sizing является CSS свойством, определяющим, как размер элемента должен быть вычислен в отношении его отступов (padding), рамок (border) и внутреннего содержимого (content). Это свойство принимает два основных значения: border-boxи content-box, которые изменяют способ вычисления общих размеров элемента.

box-sizing: border-box;При настройке общая ширина и высота элемента включают отступы и рамки. Это означает, что если мы устанавливаем элемент ширину 100px и добавляем рамку шириной 10px и отступ 5px, общая ширина элемента останется 100px, а содержимое соответственно уменьшится.
box-sizing: content-box;Это значение стандартно и означает, что ширина и высота элемента относятся только к содержимому, не включая рамки и отступы. Так, если мы устанавливаем ширину элемента 100px, добавляем рамку 10px и отступ 5px, общая ширина элемента будет составлять 130px (100px содержимое + 10px рамка с каждой стороны + 5px отступ с каждой стороны).

Пример кода:
/* Використання box-sizing: border-box */
.element1 {
    box-sizing: border-box;
    width: 100px;
    padding: 10px;
    border: 5px solid black;
    /* Загальна ширина елемента буде 100px, включаючи вміст, рамку і відступи */
}

/* Використання box-sizing: content-box */
.element2 {
    box-sizing: content-box;
    width: 100px;
    padding: 10px;
    border: 5px solid black;
    /* Загальна ширина елемента буде 130px */
}

В первом случае.element1сborder-boxобщая ширина элемента остается 100px, независимо от отступов и рамок. Во втором случае.element2сcontent-boxобщая ширина составит 130px, поскольку к 100px ширине содержимого добавляются рамки и отступы. Выбор между этими двумя свойствами зависит от потребностей макета и предпочтений разработчика.

6. Эксперименты по overflow :
Создайте контейнер с ограниченными размерами и добавьте содержимое, превышающее эти размеры.

Свойство overflow
Свойство overflow в CSS определяет, как мы обрабатываем содержимое элемента, выходящего за пределы определенных размеров его контейнера. Это свойство помогает нам контролировать поведение содержимого, которое переполняет свой блок, позволяя решить, должно ли это содержимое быть обрезано, прокручиваемым, или должно ли оно остаться видимым.

Мы используем overflowдля решения разных задач:

Для предотвращения выхода содержимого за пределы контейнера: Если мы хотим, чтобы содержимое, не помещаемое в блок, не было видимым, мы можем использовать overflow: hidden;.
Для создания прокрутки: Если содержимое должно быть доступно через вертикальную или горизонтальную прокрутку, мы устанавливаем overflow: scroll;или overflow: auto;, где последний автоматически отображает полосы прокрутки, когда это необходимо.
Для визуальных эффектов и анимации: Например, можно создать эффект "всплывания" с помощью обрезки содержимого и его анимации в контейнере с overflow: hidden;.

Пример кода с описанием:
<div style="width: 200px; height: 100px; overflow: auto;">
  <p>
    Цей текст є досить довгим, щоб не вміщуватися у контейнер розміром 200x100 пікселів.
    Завдяки overflow: auto, з'являться смуги прокрутки, щоб можна було прокручувати
    і бачити весь вміст.
  </p>
</div>

В этом примере контейнер с фиксированной шириной и высотой содержит абзац текста, слишком длинный для отображения без прокрутки. Свойствоoverflow: auto;обеспечивает появление полос прокрутки в контейнере, если все содержимое не может быть показано одновременно, позволяя пользователю прокручивать его для просмотра.

7. Позиционирование элементов : Кроме стики
Используйте разные типы позиционирования (static, relative, absolute, fixed, sticky) на разных элементах.
Создайте примеры, демонстрирующие разницу между fixed и sticky.

Указания позиции элемента
Left, top, right, и bottom это CSS свойства, которые мы используем для указания позиции элемента по отношению к его ближайшим позиционированным предкам. Они работают только для элементов, имеющих позиционирование, отличное от static, то есть relative, absolute, fixedили sticky.

left и right контролируют горизонтальное позиционирование элемента.
top и bottom контролируют вертикальное позиционирование.

Примеры применения:
Примеры применения различных значений свойства positionв CSS:

Static (статическое позиционирование) – это значение по умолчанию, не требующее явного определения, поскольку элементы автоматически располагаются в обычном потоке документа.

<div>Я статично позиціонований блок і слідую звичайному потоку документа.</div>


Relative (относительное позиционирование) – элемент смещается по отношению к его начальной позиции в нормальном потоке документа, не влияя на размещение других элементов.

<div style="position: relative; left: 20px; top: 10px;">Я зміщений на 20px праворуч і 10px вгору від моєї звичайної позиції.</div>


Absolute (абсолютное позиционирование) – элемент удаляется из нормального потока документа и располагается относительно его ближайшего позиционированного предка (неstatic).

<div style="position: relative; height: 100px;">
  <div style="position: absolute; bottom: 0; right: 0;">Я абсолютно позиціонований внизу праворуч мого батьківського блоку.</div>
</div>


Fixed (фиксированное позиционирование) – элемент фиксируется на одном месте окна браузера и не двигается во время прокрутки страницы.

<div style="position: fixed; bottom: 0; left: 0; width: 100%;">Я фіксований внизу вікна переглядача.</div>
