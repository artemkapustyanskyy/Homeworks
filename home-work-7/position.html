Проверка position

На этой странице я буду проверять как работает свойство position

Свойство position определяет, как элемент позиционируется на странице

Тип Static элемент будет дефолтным (как ранее)

Тип Absolute элемент будет смещаться относительно родителя с position:static

Тип Relative элемент будет смещаться относительно своего установленного положения

Тип Fixed элемент будет смещаться относительно окна браузера
